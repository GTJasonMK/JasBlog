    Python 22：类型标注能检查什么，又不能检查什么

    我把类型标注看作写给编辑器、检查器和调用者的接口说明。它能提前发现一部分误用，但不会替代码检查文件或 HTTP 请求里真正传进来的值。

  2. 学习笔记2026-11-12

    Python 23：用 pytest 把预期行为留下来

    一个测试对我有没有用，主要看它能不能说清楚：什么输入，在什么条件下，应该得到什么结果。空输入和失败路径尤其值得写下来，免得以后改代码时只记得正常情况。

    Python 24：调试、日志与配置：留下能解释问题的信息

    调试时，我会先找到数据从哪一步开始不符合预期，再决定往哪里加日志。比起到处打印“执行到了这里”，输入范围、处理数量和异常堆栈更能解释发生了什么。

    Python 33：自动化脚本：先让任务能安全重跑

    一个脚本第一次跑通之后，我会接着考虑第二次运行会怎样：会不会覆盖结果、重复处理，或者把已经改过的文件再改一次。输入、转换和输出分开，才能逐步把这些情况讲清楚。
