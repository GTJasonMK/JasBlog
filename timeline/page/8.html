    Python 05：列表、元组和解包该怎么选

    一组数据放进什么容器，取决于接下来要怎么用它。需要增删就选列表，固定位置的少量数据可以用元组；只是循环计数时，通常没有必要先造一个列表。

    Python 06：字典与集合：查找、去重和成员判断

    如果问题是“这个名字对应什么”，我会先想到字典；如果问题是“有没有、是否重复”，集合往往更合适。选对结构，比在列表上多写几个循环更直接。

  10. 学习笔记2026-11-12

    Python 07：条件、循环与推导式：把处理过程写清楚

    推导式能把一段过滤或转换写得很短，但短不一定好读。我通常先用普通循环把处理顺序写清楚，确认只是简单映射或筛选后，再考虑改成推导式。

  11. 学习笔记2026-11-12

    Python 08：函数、返回值与作用域

    写函数时，我会先想清楚输入和输出。比如计算平均值，调用者需要拿到结果继续使用，所以应该返回数值；打印结果只是展示，不该和计算绑在一起。

    Python 09：参数、闭包与函数式工具
