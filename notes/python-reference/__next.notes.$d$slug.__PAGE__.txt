## 容器与数据表示

| 结构 | 用途 | 核心区别 |
|---|---|---|
| `list` / `dict` | 通用 Python 数据 | 灵活、逐对象处理 |
| NumPy `ndarray` | 数值计算 | 同类型、多维、向量化 |
| pandas `DataFrame` | 带标签表格 | 行列标签、缺失值和表格变换 |
| PyTorch `Tensor` | 深度学习计算 | 多维数值、设备与自动求导 |

## 同步、线程、进程与异步

先区分瓶颈：等待网络或磁盘时考虑线程或异步 I/O；CPU 计算密集时考虑多进程或 NumPy/PyTorch 等原生实现。再测量实际性能，不能仅凭语法判断。

## 生态导航

- Web：FastAPI 适合 API 教学；Django 提供更完整的 Web 框架和管理站点；Flask 更轻量。
- 爬取和自动化：HTTP API 优先；HTML 解析可看 Beautiful Soup；浏览器交互可看 Playwright。
- 科学计算：NumPy、SciPy、Matplotlib；数据表格用 pandas。
- GUI：Tkinter 属于标准库入门方向；更完整桌面应用可了解 PySide。
- 办公文件：`openpyxl` 处理 Excel，`python-docx` 处理 Word。
- LLM 应用：先掌握 HTTP、JSON、异步 I/O 和安全管理，再学习模型 API 与检索增强等工具。

这些方向的操作示例放在[网页采集、办公与其他扩展方向](/notes/python-43-other-domains)中。继续做具体业务时，还需要结合相应领域的数据和使用要求。
