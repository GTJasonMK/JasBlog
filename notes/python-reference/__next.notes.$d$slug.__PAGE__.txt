## 容器与数据表示

| 结构 | 用途 | 核心区别 |
|---|---|---|
| `list` / `dict` | 通用 Python 数据 | 灵活、逐对象处理 |
| NumPy `ndarray` | 数值计算 | 同类型、多维、向量化 |
| pandas `DataFrame` | 带标签表格 | 行列标签、缺失值和表格变换 |
| PyTorch `Tensor` | 深度学习计算 | 多维数值、设备与自动求导 |

若只是保存几个不同类型的配置值，字典通常足够；要对大量同类型数值做逐元素运算，数组更合适；需要按列名连接、分组和处理缺失时，表格表达更直接；需要把损失传回可训练参数，则进入张量与自动求导的范围。它们能够互相转换，但复制成本、精度和设备位置不一定保留不变，转换前要知道下一步具体需要什么。

## 同步、线程、进程与异步

先区分瓶颈：等待网络或磁盘时考虑线程或异步 I/O；CPU 计算密集时考虑多进程或 NumPy/PyTorch 等原生实现。再测量实际性能，不能仅凭语法判断。

线程与协程主要改变任务如何等待和调度，不会让一个受GIL限制的纯Python计算自动并行；进程能够隔离执行，却引入启动与序列化成本。许多数组库会在原生实现中释放GIL，所以也不能只根据“它是Python程序”判断瓶颈。相关实验放在[性能](/notes/python-30-performance)、[线程与进程](/notes/python-31-concurrency)和[asyncio](/notes/python-32-asyncio)三篇。

## 生态导航

- Web：FastAPI 适合 API 教学；Django 提供更完整的 Web 框架和管理站点；Flask 更轻量。
- 爬取和自动化：HTTP API 优先；HTML 解析可看 Beautiful Soup；浏览器交互可看 Playwright。
- 科学计算：NumPy、SciPy、Matplotlib；数据表格用 pandas。
- GUI：Tkinter 属于标准库入门方向；更完整桌面应用可了解 PySide。
- 办公文件：`openpyxl` 处理 Excel，`python-docx` 处理 Word。
- LLM 应用：先掌握 HTTP、JSON、异步 I/O 和安全管理，再学习模型 API 与检索增强等工具。

这些方向的操作示例放在[网页采集、办公与其他扩展方向](/notes/python-43-other-domains)中。继续做具体业务时，还需要结合相应领域的数据和使用要求。

## 版本与维护

核心语法示例面向 Python 3.12+。框架和数据科学库更新较快，各项目应在开始时注明 Python 版本、依赖版本和安装命令；更新项目时再核对官方文档，不把本手册当作所有库 API 的永久替代品。

文档里的一个可运行片段通常只证明某个接口怎样调用。要迁入自己的项目，继续核对输入范围、异常、资源释放与依赖版本；遇到弃用提示则查该版本的变更说明。先缩小到能复现的最小例子，再查明确的对象与方法，往往比更换整套工具更快找到原因。
