Python 03：数字、真假值与类型转换

Python语言基础

录入一件商品时，数量可能是 3，价格可能是 19.9，是否上架用 True 表达，而“还没填写价格”又是另一种情况。它们都能成为变量的值，却承担着不同的含义。选类型之前，先看这份数据允许哪些操作、哪些值应该被区分。

int 表示整数，适合计数、编号和没有小数部分的数量。Python 整数不会像固定宽度整数那样在越过32位或64位边界时直接溢出，不过数值越大，占用的内存和计算成本也会增加。

float 表示二进制浮点数，适合测量值和允许近似误差的计算。bool 的两个值是 True、False，用于条件判断；None 表示缺少一个值，常用于“未设置”“没有找到”等情况。文本则用 str 保存，"12" 还只是两个字符，不能直接当作整数 12 使用。

同一个除法，为什么有两种写法#

python
print(7 / 2)       # 3.5
print(7 // 2)      # 3，向下取整
print(7 % 2)       # 1

/ 表达通常的除法，即使两边都是整数，也会得到浮点结果。// 表达向下取整的商，% 得到对应余数。把17件物品分成每箱5件，用 17 // 5 算完整箱数，17 % 5 算剩余数量，就很直接。

这里的“向下”是朝负无穷方向，所以 -7 // 2 得到 -4，不是 -3。而 int(-3.9) 的结果是 -3，它截去小数部分，方向朝零。取整、截断和四舍五入分别解决不同的问题，碰上负数时尤其不能混用。

0.1 + 0.2 为什么不正好等于 0.3#

常见十进制小数不一定能用有限位二进制表示，float 保存的是邻近的可表示值。一次相加后，屏幕上就可能看到那个很小的差异：

python
import math

print(0.1 + 0.2)                   # 0.30000000000000004
print(0.1 + 0.2 == 0.3)            # False
print(math.isclose(0.1 + 0.2, 0.3)) # True

math.isclose 按相对和绝对容差判断两个值是否接近，适合某些数值计算中的近似比较。容差应该来自问题允许的误差，不能为了让判断通过就随便放大；尤其是接近零的值，往往需要明确指定 abs_tol。

金额的要求通常更严格。如果记录最小单位是分，可以用整数保存 1990；需要十进制小数运算时，可以用 decimal.Decimal：

python
from decimal import Decimal

price = Decimal("19.90")
total = price * 3
print(total)  # 59.70

这里从字符串构造，保留输入的十进制含义。从已经有近似误差的 float 构造，并不能自动恢复原来的精确金额。最后保留几位小数、采用什么舍入规则，还需要按业务规定明确下来，Decimal 不会替你决定这些规则。

条件中的“假”和数据里的“没有”#

Python 允许直接在条件中判断对象。False、None、数值零，以及空字符串、空列表、空字典等空容器，都被视为假值。非空容器通常是真值，所以检查列表是否有内容可以直接写 if items:。

但假值之间的业务含义可能完全不同。考试得了0分与尚未录入成绩，不能合并成同一种情况：

python
score = 0
display_score = "未录入" if score is None else score
print(display_score)  # 0

如果这里写 score or "未录入"，合法的0也会被替换掉。or 返回参与运算的对象，不保证返回布尔值；它适合“所有假值都可以采用同一个默认值”的情况。需要专门识别缺失值时，就明确判断 is None。

同样，bool("False") 得到 True，因为这是一个非空字符串。读取配置中的开关值时，需要定义允许的文本，再将它解析成布尔值，不能靠 bool 猜测字符串的意思。

转换可能截断，也可能失败#

int("12") 可以得到12，int("12.5") 却会抛出 ValueError。后者不是整数格式，是否接受小数、是否允许截断，应该由接收输入的地方决定。写成 int(float(text)) 虽然可能得到一个整数，也可能悄悄把本该拒绝的小数截掉。

输入校验也要同时考虑类型和内容。假设名称字段约定为字符串或 None，可以这样检查：

python
name = "  Ada  "
if name and name.strip():
    print(name.strip())

这里先排除缺失值和空字符串，再检查去掉空格后是否还有文字。若输入还可能是数字或数组，就应该先验证它是否符合字段类型，不能直接调用 .strip()。转换能让数据进入下一步，也会改变数据的含义；调用成功只说明这种转换可以执行，并不代表它符合当前业务。
