TypeScript 与全栈开发术语速查

TypeScript

目录

  • 几组容易连错的关系

报错说模块解析失败，应该查运行工具还是数据库？同一个项目里的术语分属不同层，先放回它实际发生的位置，才能选对文档与验证方式。这份速查用于定位，不把一句定义当成完整行为保证。

术语含义
API程序之间交换数据的接口；这些示例主要使用 HTTP API。
Async / awaitJavaScript 中编写异步流程的语法，底层仍基于 Promise。
编译将源代码转换成目标代码；转译工具不一定执行类型检查，TypeScript 项目仍需单独运行类型检查。
Cookie浏览器按域名和策略保存、随请求发送的小段数据。
DOM浏览器对 HTML 文档的对象表示，供脚本读取和操作。
泛型编写可复用代码时保留类型信息的一种参数化方式。
HTTP浏览器与服务器常用的请求/响应协议。
MiddlewareExpress 请求处理链中的函数，可检查或修改请求、响应并继续传递。
npmNode.js 常用的包管理器。
Prisma这些示例使用的数据库 Schema、迁移和查询工具。
React用组件构建浏览器用户界面的 JavaScript 库。
REST以资源和 HTTP 方法组织 API 的常见设计风格。
Schema对数据结构及其约束的描述；Zod Schema 还可以在运行时校验数据。
Type inference编译器根据上下文推导类型，减少手工标注。
Type narrowing根据条件检查把宽泛类型缩小到更具体的类型。
TypeScript为JavaScript增加静态检查；接口与类型注解通常在运行前移除，不自动验证外部数据。
Vite这些示例用于开发和构建 React 前端的工具。
Workspace一个仓库中由包管理器统一管理的多个相关项目。

几组容易连错的关系#

Promise描述异步结果，await让当前函数在等待后继续，不自动建立线程；React把状态变成界面，DOM则是浏览器实际操作的文档树。它们组合工作，但不能用“异步页面”笼统代替执行机制。

TypeScript类型与Zod Schema都描述结构，前者主要检查已知代码关系，后者可以读取真实值并执行规范化。Prisma再把数据库模型变成查询接口，仍不决定用户能访问哪行。三者都出现了Task，也没有任何一个能单独替代另外两层。

Cookie是浏览器携带的数据，服务端会话是服务器据此恢复身份的状态；HttpOnly、Secure与SameSite分别限制不同访问条件，不等同于资源授权。API认证用户后，查询还要限制ownerId。

构建生成制品，类型检查与行为测试提供不同证据，部署让制品按配置运行。遇到“本机能跑”，继续追问使用了哪个命令、读了哪份配置、是否真执行过迁移与生产入口，问题就能从模糊术语缩到具体过程。
