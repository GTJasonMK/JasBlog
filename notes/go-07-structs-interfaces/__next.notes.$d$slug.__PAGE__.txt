结构体与组合\n\n结构体把有关联的字段放在一起。Go 常通过嵌入和组合复用行为，而不是建立深层继承树。\n\n~~~go\ntype Product struct {\n\tID    int64\n\tName  string\n\tPrice int64 // 以分为单位\n}\n~~~\n\n真实 API error)\n}\n~~~\n\n如果接口只有一个实现且没有测试或边界需求，不要过早抽象。接口的价值在于明确调用者需要什么，并允许替换外部依赖。\n\n接口值同时包含动态类型和值。把一个 nil 指针赋给接口后，接口本身通常不等于 nil；这类 typed nil 是常见陷阱。判断接口错误时应直接用 err == nil、errors.Is 或
