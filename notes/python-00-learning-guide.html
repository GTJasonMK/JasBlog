我把 Python 笔记按语言、程序组织、工程实践和应用分开，方便顺着学，也方便遇到问题时回头查。理解赋值、可变对象和迭代之后，再去看数据分析或 API 代码，许多行为就有了可以解释的依据。

刚接触 Python，可以从解释器、对象和容器开始。已经会写脚本，则可以直接找虚拟环境、测试、类型标注和异步。应用部分保留了 ETL、销售分析、Iris 分类、PyTorch 和任务 API 的完整示例。
