需要确认隔离、索引、恢复或产品限制时，我会沿这里的官方入口查具体版本。主线使用 PostgreSQL 16，MySQL 对照限定 8.4 与 InnoDB，不能把不同版本的行为混成同一个结论。

原资料记录了对 PostgreSQL 隔离级别、并发建索引、基础备份与 PITR，以及 MySQL 8.4 隔离、DDL 资料和镜像说明的核对。当时实验采用本机已有的 16.15，版本相关命令再以 16 版资料和实际运行核对。其余链接作为按主题继续阅读的入口，遇到版本差异以对应版本官方说明和实际实验为准。

第 23 章：常用数据库选型资料#

以下资料用于核对产品定位、数据模型、事务与部署边界。PG 与 MySQL 沿用上面的版本资料；其余产品的版本、授权和商业功能应在正式选型时单独记录。

类别或产品官方资料与阅读重点
SQLite、MariaDBSQLite 适用场景、MariaDB Server 文档：部署、并发及版本差异
Oracle、SQL ServerOracle 概念、SQL Server 概述：数据模型、工具、平台与版本范围
达梦、人大金仓达梦安装与迁移、金仓官方文档：产品版本、兼容模式、驱动、迁移和平台适配
TiDB、OceanBase、CockroachDBTiDB 概述、OceanBase 官方项目、CockroachDB 官方项目：分布式事务、协议兼容、组件与部署范围
Redis、Valkey、MemcachedRedis 持久化、Valkey 文档、Memcached 文档：数据结构、持久化、复制与缓存职责
MongoDB多文档事务：单文档原子性、部署与读写关注配置
Cassandra、HBaseCassandra 架构、HBase 官方入口：分区、RowKey、一致性与访问模型
DynamoDB、Cosmos DBDynamoDB 核心组件、Cosmos DB 概述：分区、索引、一致性与计费模型
Elasticsearch、OpenSearchElastic 产品与部署、OpenSearch 介绍：搜索、索引、部署及生态边界
ClickHouse、Doris、StarRocksClickHouse 概述、Doris 概述、StarRocks 官方项目：列式分析、表模型、导入与关联
DuckDB、Snowflake、BigQueryDuckDB 官方项目、Snowflake 架构、BigQuery 概述：进程内分析与托管数仓的部署和成本边界
InfluxDB、TimescaleDBInfluxDB 3 Core、TimescaleDB 官方项目：时序模型、版本与扩展；Timescale 厂商文档现使用 Tiger Data 品牌
Neo4j图数据库入门：属性图、Cypher 与图遍历
pgvector、Milvus、Qdrantpgvector 官方项目、Milvus 官方项目、Qdrant 概述：精确与近似检索、过滤、索引和部署形态

第 23 章比较产品的用途与代价，未对这些产品统一部署、跑分或核验全部商业功能。BigQuery 概述抓取遇到网络超时，金仓文档入口需要浏览器加载，保留官方入口供实际选型时核对；相应产品未计入逐页功能核验。

示例中的时长和机器资源建议只用于安排练习，不能作为数据库产品的性能或服务承诺。
