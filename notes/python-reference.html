Python 资料索引与常用工具

遇到具体 API 或版本差异时，我会回到官方文档核对。这里把常用数据结构、应用方向和资料入口放在一起，方便查找。

容器与数据表示#

结构用途核心区别
list / dict通用 Python 数据灵活、逐对象处理
NumPy ndarray数值计算同类型、多维、向量化
pandas DataFrame带标签表格行列标签、缺失值和表格变换
PyTorch Tensor深度学习计算多维数值、设备与自动求导

同步、线程、进程与异步#

先区分瓶颈：等待网络或磁盘时考虑线程或异步 I/O；CPU 计算密集时考虑多进程或 NumPy/PyTorch 等原生实现。再测量实际性能，不能仅凭语法判断。

生态导航#

  • Web：FastAPI 适合 API 教学；Django 提供更完整的 Web 框架和管理站点；Flask 更轻量。
  • 爬取和自动化：HTTP API 优先；HTML 解析可看 Beautiful Soup；浏览器交互可看 Playwright。
  • 科学计算：NumPy、SciPy、Matplotlib；数据表格用 pandas。
  • GUI：Tkinter 属于标准库入门方向；更完整桌面应用可了解 PySide。
  • 办公文件：openpyxl 处理 Excel，python-docx 处理 Word。
  • LLM 应用：先掌握 HTTP、JSON、异步 I/O 和安全管理，再学习模型 API 与检索增强等工具。

这些方向的操作示例放在网页采集、办公与其他扩展方向中。继续做具体业务时，还需要结合相应领域的数据和使用要求。

官方资料#

  • Python Tutorial：语法、数据结构、模块、异常、类、标准库和环境。
  • Python Packaging User Guide：虚拟环境、依赖、打包和发布。
  • Writing pyproject.toml：构建后端、项目元数据和包发现配置。
  • NumPy Quickstart：数组、shape、axis 和向量运算。
  • pandas Getting Started：读写、筛选、汇总、重塑、合并、时间序列和文本。
  • scikit-learn Getting Started：估计器、预处理、模型选择和评估。
  • PyTorch Learn the Basics：数据、模型、优化和保存加载工作流。
  • FastAPI Tutorial：类型、请求模型、依赖、错误和 API。
  • SQLModel Tutorial：FastAPI 常用的类型化 SQL 数据模型与数据库会话。
  • Django Tutorial：完整 Web 应用实践。
  • pytest Get Started：测试组织和运行。
  • asyncio Coroutines and Tasks：任务组、取消、超时和并发等待。
  • Tkinter：Python 标准库 GUI。
  • SciPy User Guide：科学计算算法。
  • openpyxl Documentation：Excel 工作簿操作。
  • Beautiful Soup Documentation：HTML/XML 解析。

版本与维护#

核心语法示例面向 Python 3.12+。框架和数据科学库更新较快，各项目应在开始时注明 Python 版本、依赖版本和安装命令；更新项目时再核对官方文档，不把本手册当作所有库 API 的永久替代品。
