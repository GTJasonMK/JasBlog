决定用值接收者还是指针接收者之前，我会先确认这个方法是否需要改原对象，以及复制成本有多大。方法集和接口能否匹配，也要一起考虑。

## 函数与返回值

Go 函数可以返回多个值，最常见的用途是同时返回结果和错误。命名返回值适合少数能明显改善可读性的场景，不要把函数写成依赖隐式修改返回变量的形式。

defer 会在当前函数返回前按后进先出的顺序执行，适合释放锁、关闭文件和取消 context。defer 调用的参数在 defer 语句执行时求值；不要在长循环里持续 defer 资源关闭，否则资源会等到外层函数返回才释放。

~~~go
func divide(a, b int) (int, error) {
	if b == 0 {
		return 0, errors.New("除数不能为零")
	}
	return a / b, nil
}
~~~

需要导入 errors 包。调用者应显式检查错误，而不是假设结果总是有效。

## 方法与指针

方法是带接收者的函数。值接收者会复制接收者值；指针接收者可以修改原值，也避免复制较大的结构体。一个类型的方法集会影响它是否满足接口，因此应在类型设计时保持一致。

~~~go
type Counter struct{ n int }

func (c *Counter) Add(delta int) {
	c.n += delta
}
~~~

Go 会在可取地址的变量上自动处理常见的 c.Add(1) 调用，但接口实现仍要看方法集。

## 闭包读到的变量由语言版本和声明方式决定

闭包捕获的是变量，不一定是循环中每次的快照。Go 1.22 起，模块的 go 指令声明为 1.22 或更高时，循环变量按每次迭代分别创建；旧 go 指令仍保留旧语义。并发代码显式传递任务参数通常更容易阅读，也便于兼容旧模块。

## 动手验证

实现 Counter 的读取与递增方法；让递增方法返回当前值，并写一个函数对除零返回错误。
