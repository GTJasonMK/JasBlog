# 照片、目录与阅读界面

本轮采用湖绿与暖白作为主要颜色。首页保留照片的完整构图，用错位栏目卡片和各自的线稿区分代码、笔记、摄影与图谱；内容页使用独立纸面，背景只留在外围，不再透进长篇正文。

## 内容与布局

站点名称、格言、介绍、栏目文字和可见性均读取站点配置。首页入口保持配置顺序，不增加重复导航。笔记数量来自公开文章，不写死数量或虚构作品。

首页站点名和介绍从首屏显示。右侧格言按完整字形打出、停留、删除，再依次显示栏目。动画只播放一遍，Escape 可以提前进入栏目选择；搜索开启时 Escape 先关闭搜索。系统减少动效或禁用脚本时直接显示完整格言和入口。

格言提前排好位置，逐字变化不改变换行；屏幕阅读器读取完整格言，不逐字播报。栏目只使用透明度和位移的进入动效，尚未出现的入口不参与键盘焦点。离开首页时清理定时器，系统动效偏好变化时停止动画。

栏目名称由顶栏展示，笔记、项目、图谱、规划、日志和摄影列表不再重复显示栏目大标题与介绍。页面保留读屏需要的标题语义，浏览器标题和搜索元数据继续来自站点配置。笔记直接展示分类、筛选和文章，数量放在筛选栏中。每页最多 12 篇，底部以页码和上一页、下一页切换，当前页突出显示，长页码序列只保留首尾和相邻页。翻页回到文章区域，切换分类或标签回到第一页。默认页内容由服务端输出，避免首屏等待查询参数组件加载后再出现；每个页码对应独立静态地址，无脚本时仍可翻页。只有参数读取器进入 Suspense，列表实例保持不变；筛选事件只更新 URL，再由读取器同步查询快照，没有两套展示实现。桌面左侧显示多级分类，右侧显示双列文章；窄屏改为上方分类与单列文章。标签采用原生筛选控件，保留完整选项，避免把所有标签堆在文章之前。分类与卡片复用共享组件，筛选复用 content-core。

分页与回到顶部位于列表末尾的同一操作行，回顶按钮靠右，取消按钮原有的独立上间距。回顶按钮的列宽固定，显隐不会挤动分页；单页结果仅显示需要的回顶按钮，空操作行不占空间。

文章标题使用系统衬线字体，正文保留系统无衬线字体；不加载远程字体。正文和标题位于连续实色阅读面，宽屏目录独立固定在右侧，窄屏目录可展开。代码、宽表格和图表在自身区域滚动，不推动整页横向滚动。

项目、摄影、图谱和规划列表沿用共享内容组件，直接展示内容，取消重复的标题区和嵌套空状态框。没有内容时只显示紧凑提示；摄影有作品时保留相册底色，保证筛选和图片说明清楚。摄影作品尚未整理时保留真实空状态，背景照片不混入作品清单。文章、项目和独立页面详情继续展示各自的内容标题。

友链 `/pages/friends` 复用独立页面与 Markdown，顶栏和首页入口来自同一条导航配置。博客用 `friends-page` 命名样式提供紧凑列表，页面标题保留读屏语义，正文不重复展示导航已有的名称；名单为空时仅显示简短提示。站点名称、链接和简介通过编辑器中的普通 Markdown 列表维护，宽屏自动分列，窄屏完整换行。友链首页入口使用同一套线稿图标。

## 主题与组件边界

- site-theme.css 在博客侧映射共享颜色变量，分别定义浅色与深色。湖绿用于动作与选中状态，暖白用于阅读，正文和代码保留明确的对比度。
- globals.css 负责背景、页头、搜索、页脚；portal.css 负责首页；content.css 负责目录和阅读表面。共享组件样式先加载，博客样式随后加载。
- 博客的照片和排版不进入编辑器预览。编辑器继续使用同一内容合同与共享组件的默认主题。
- content-ui 0.7.0 的 NoteCategoryNavigation 统一使用嵌套列表呈现分类，子分类紧跟父分类。当前分类唯一选中，只有一个“全部笔记”入口，箭头独立展开与收起；深层分类链接自动展开祖先。窄屏默认收起目录，入口显示当前分类；展开后定位到当前选项，选择分类后收起并将焦点还给入口，目录展开区域限制高度。桌面保留左侧目录树。PublicationTime 统一展示各类内容的首次发布时间，时间线与笔记共享分页，回顶仍与分页同行。列表、标题和空状态继续使用共享样式入口，没有复制分类实现或内容数据。
- site-tools 0.7.0 在发布构建前自动记录缺失的首次时间，普通构建不写内容。摄影素材清理只针对从 public 复制的素材，保留框架生成的页面和路由文件。

页头保留悬浮圆角玻璃导航，导航周围使用同一个 SiteBackground 组件补齐照片，并把这层照片裁切在页头范围内，遮住滚入顶部空隙的卡片。照片沿用视口取景和同一资源地址，保持背景构图一致。玻璃滤镜只放在导航内部的独立伪元素上，搜索和菜单遮罩仍按整个视口定位。阅读面不使用滤镜。首页线稿由本地 SVG 绘制，不增加图片依赖；页面不使用粒子、视频或持续动画。

## 验证范围

真实静态页面覆盖首页、目录、正文、长表格、摄影空状态、项目、图谱、规划和 404。按 320、390、768、1024、1280、1440、1920px 检查明暗主题；390、1024、1440px 运行 axe。检查分类、标签、前后跳转、搜索、菜单焦点、目录、复制、代码滚动、下载、主题与动效偏好。

摄影非空状态另用隔离的合成夹具验证分类、大图、方向键、边界禁用、Escape 和关闭后的焦点恢复；测试夹具不发布到网站。另检查无脚本导航、笔记翻页与文章阅读，以及实际生产构建的 Lighthouse 性能、无障碍、最佳实践与 SEO。
