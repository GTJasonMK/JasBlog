# 友链

友链地址为 `/pages/friends`，内容保存在 `content/pages/friends.md`，顶栏和首页入口由站点导航中的 `page:friends` 提供。目前没有名单，页面保留真实空状态。

在编辑器的“独立页面”中打开 `friends.md`（标题为“友链”），编辑正文并保存。添加站点时删除空状态文字，使用普通 Markdown 列表，每项包含名称、网址和可选简介：

```markdown
- [站点名称](https://example.com/)

  一句话介绍。

- [另一个站点](https://example.org/)

  另一段介绍。
```

列表顺序就是展示顺序。页面复用现有 Markdown 渲染、独立页面预览和发布流程；外部网页链接在新标签页打开。分组可以使用二级标题。

页面文件名 `friends.md` 是固定地址，修改显示名称请编辑标题和导航标签。设为草稿或在导航设置中隐藏入口，沿用独立页面的公开规则；删除页面前先移除导航引用。

博客为这个地址提供紧凑样式，不重复显示顶栏已有的大标题。编辑器使用现有独立页面预览，不承担页面编排。
