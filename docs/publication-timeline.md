# 发布时间线

时间线位于 `/timeline`，汇总公开的笔记、项目、图谱、规划、日志、摄影和独立页面。每项包含首次发布时间、内容类型、标题、简介及对应内容链接。只记录首次发布，修改正文、改名、重新构建或再次发布不新增动态。

按月分组、按时间倒序，每页最多12项。后续页为 `/timeline/page/2` 等独立静态地址，分页和回到顶部并排。草稿和未公开栏目不出现；导航隐藏与内容公开仍相互独立。时间线栏目及导航名称可在编辑器的站点设置中管理。

各类文档的 frontmatter 和摄影清单使用 `publishedAt` 保存首次时间。推荐发布流程 `npm run commit:content` 或编辑器的“发布”在校验通过后、构建前自动记录缺失时间，已有值保持不变。普通开发与构建不写时间。发布失败后保留已记录值，恢复发布沿用它，是否真正上线仍由原部署验证决定。

在编辑器的文章属性或摄影属性中，可以补录首次发布日期和时间。日期可以单独填写；时刻按北京时间输入，保存完整ISO时间。文档原 `date` 是内容日期，摄影 `takenAt` 是拍摄日期，各自保留。

历史迁移只把已有日期复制到 `publishedAt`，不会用文件修改时间或当前构建时间伪造历史时刻。只有日期的记录显示到日；缺少历史日期的项目放在“日期待补录”分组。迁移时195份文档中194份按原日期补录，友链页没有原日期，在本次首次上线前记录发布时间。

迁移原始备份在 `.run/publication-timeline/content-backup`，迁移时的前后校验值见 [元数据迁移记录](content-migrations/first-publication-manifest.json)。195份文档的正文摘要一致。原学习资料导入映射仍保留导入时快照，新的记录说明后续合法元数据变更；这些历史校验值不限制今后的正常内容编辑。
