```bash

.venv/bin/python scripts/package.py --destination ../JasBlog/public/downloads --notes ../JasBlog/content/notes
```

打包要求学习仓库已提交。固定版本文件存在且字节不同时拒绝覆盖；已有文章或历史下载相对生成清单发生外部修改时也停止。原数据库下载的初始摘要作为首次迁移依据保留，后续只认生成清单。

## 教学质量要求

先交代业务输入、数据归属与成功条件，再沿调用解释代码如何维护这些条件。重要配置说明作用过程、选择依据、依赖和错误后果。基础章节不机械添加相同生产清单，工程章节负责串起完整路径。

每阶段验证成功、失败、重复、越权或中断中的实际相关风险，同时核对响应和持久结果。工作流保留进度与成果，输入变化只处理受影响阶段。数据许可、版本、模型划分、性能条件和原始失败证据属于交付内容。

Kubernetes 需要完整代码与详细讲解，实际集群部署不作为本轮必过项。结构与 Schema 检查、镜像构建、本地行为、集群业务和跨主机演练分别记录。未运行的内容不能填为通过，也不能用站点构建成功替代工程验证。
