# 首次发布时间元数据迁移

本次为195份公开Markdown文档增加首次发布时间支持，其中194份有原始 `date`，按原值补录到 `publishedAt`。友链页没有原日期，保留待补录状态。没有采用文件修改时间或迁移执行时刻来替代历史日期。

变更仅涉及frontmatter。全部正文的SHA-256与迁移前一致，原始字节另存于本地迁移备份，重复迁移返回零变更。[迁移记录](first-publication-manifest.json)逐项保存路径、迁移前后文件摘要和正文摘要。

学习资料导入映射中的目标文件摘要是导入时的快照，本次新增字段使整文件摘要发生预期变化。源资料与正文没有重写，历史快照保持不变。后续正文编辑属于正常创作，不要求改写历史迁移记录。
