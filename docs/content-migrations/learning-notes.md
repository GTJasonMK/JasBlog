## 技术修正

- Python：`venv` 属于标准库；`pip` 是独立维护的安装工具，常随解释器安装或由 `ensurepip` 引导。
- JavaScript：把原文的“真假值”改为“常见假值”，准确描述列出的值。
- Promise 示例：增加 `response.ok` 检查，避免将 HTTP 失败当作成功数据。
- Promise 并发：说明 `Promise.all` 拒绝不会自动取消已启动的其他任务。
- TypeScript：修正可选参数与 `undefined` 的关系，并说明可选回调参数的含义。
- 注册流程：补充数据库唯一约束和并发唯一键冲突的处理，避免只靠提前查询判断邮箱唯一。
- 术语表：区分代码转译与类型检查，避免误以为所有构建工具都会执行类型检查。

Go 官方下载接口 `https://go.dev/dl/?mode=json` 在整理时返回稳定版 `go1.27.4` 和 `go1.26.11`。保留原资料基于 Go 1.27 的示例约定，实际项目仍应固定并验证依赖版本。
