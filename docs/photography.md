# 摄影作品

页面地址为 `/photography`，入口位于站点导航。作品按清单顺序展示，支持分类筛选、原比例大图、左右键翻页和 Escape 关闭。

## 添加作品

在 JasBlog 目录执行：

```sh
npm run photo:add -- "/你的照片目录/IMG_1234.jpg" --title "山间暮色" --category "风景" --alt "夕阳照亮远处山脊与近处的草坡" --date 2026-11-12 --location "祁连山" --camera "Fujifilm X-T5"
```

`--title` 必填，其他文字字段可省略。未填写 `--alt` 时以标题作为图片描述。`--id` 可明确指定作品 ID，默认使用原文件名；重复 ID 或已有图片目录会拒绝导入。

导入结果默认是草稿，可在 JasBlogEditor 的摄影入口编辑信息、排序并设为公开。编辑器支持批量导入和中断恢复。站点与发布操作见 [站点管理](./site-management.md)。

导入生成最长边 640px、960px 的响应式预览和最长边 2560px 的大图。小照片不会放大，也不生成重复尺寸。图片保持原比例、纠正 EXIF 方向、移除 EXIF/GPS 元数据，原片不修改。相机、地点和日期只展示明确填写的信息。

新增作品排在最前面。提交发布时，必须将 `content/photography/photos.json` 和 `public/photography/` 的对应图片一并纳入 Git 提交，再走站点已有的静态构建与发布流程。

## 整理作品

清单位置为 `content/photography/photos.json`。调整数组顺序可重新策展；编辑标题、描述、分类等文字不需要重新导入图片。删除作品时，先移除清单条目，再删除对应的 `public/photography/<id>/` 目录。

每条作品包含 `id/title/alt/publication/images`，可选 `category/takenAt/location/camera`。`images` 按宽度递增排列，每项包含 `src/width/height`，最后一项用于大图。它们应当是同一作品、同一比例的不同尺寸。本地图片路径以 `/photography/` 开头，也可使用 HTTPS 图片链接，但须提供正确的尺寸和稳定地址。

页面使用系统无衬线字体，构建与阅读均不需要获取远程字体。照片尺寸预留布局空间，缩略图按需加载，大图在打开灯箱后加载。

不添加虚构作品。空清单显示“作品整理中”；错误清单或缺失本地图片会使构建失败，图片在浏览器加载失败时显示明确反馈。

导入期间使用 `.run/site-tools.lock` 防止并发覆盖，清单以临时文件原子替换。命令行普通导入失败会清理本次文件；编辑器的导入请求保存进度，恢复时核对输入及已生成产物。无效锁或变化后的原片会明确报错并保留成果。
